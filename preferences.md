# General User Preferences

These are cross-project preferences that apply to all interactions.

## Planning

- **Clear context between discrete plan sections:** When a plan has multiple independent sections that don't rely on each other, clear context between them so each section starts fresh without unnecessary baggage.
- **Include a research summary in plans:** Every plan should have a section describing what was searched (which folders, files, etc.), what was useful for producing the plan, and what wasn't. This lets the implementing agent skip unnecessary research and go directly to the right locations.
